# 🍔 LoboFood

## 🍽️ Descripción del Proyecto

LoboFood es una aplicación web para gestión de pedidos en cafeterías de CU, diseñada para simplificar el proceso de toma de órdenes y mejorar la experiencia de usuarios y administradores. Desarrollada con PHP en el backend y un frontend  con HTML, CSS y Bootstrap, ofrece una interfaz intuitiva para registrar pedidos, gestionar menús y visualizar órdenes en tiempo real.

---

## 🛠️ Tecnologías Empleadas
### Backend
- **PHP 8+** - Lógica del servidor
- **MySQL** - Base de datos relacional

### Frontend
- **HTML5 + CSS3** - Estructura y estilos
- **Bootstrap 5** - Framework de diseño responsive
- **JavaScript** - Interactividad del cliente
